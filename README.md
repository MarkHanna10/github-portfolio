# Portfolio

Source for my personal site: [markhanna10.github.io/github-portfolio](https://markhanna10.github.io/github-portfolio/)

A single static page with no build step: HTML, CSS and one image, served by GitHub Pages. The type is Archivo, using the width axis to set the expanded name in the header. The header's football-pitch markings nod to my World Cup 2026 Predictor project.

To preview locally:

```bash
python3 -m http.server 8000
```
