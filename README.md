# Portfolio

Source for my personal site: [markhanna10.github.io/github-portfolio](https://markhanna10.github.io/github-portfolio/)

A single static page with no build step: HTML, CSS, a few lines of JavaScript for the section nav, and project images, served by GitHub Pages. Type is IBM Plex Sans. The accent colour is Western purple. The page follows the reader's light or dark mode setting.

To preview locally:

```bash
python3 -m http.server 8000
```
