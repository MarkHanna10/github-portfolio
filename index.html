World Cup 2026 Predictor

A prediction game for the 2026 World Cup, built 50/50 with Karim Assaad. A trained model forecasts every match, players submit picks, and private leagues compete on a live leaderboard. Over 120 people across 8 leagues played during the tournament.

  • Logistic regression trained on 2,448 international matches, 68.6% cross-validated accuracy
  • 10,000 simulated tournaments for each team's odds of reaching every round
  • Live scores pushed to the browser through Supabase Realtime, polled every minute by an Edge Function
  • Daily data refresh and redeploy through GitHub Actions
  • Row-level security on every table, 23 unit tests in CI

React, Vite, Tailwind CSS, Supabase, PostgreSQL, Python, scikit-learn, GitHub Actions
