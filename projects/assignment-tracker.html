Assignment Tracker

An event-driven simulation of a course's assignment workflow. Students work, submit and get graded on timers, and an observer reports every change the moment it happens.

SE 2202, Western University

Assignment lifecycle

Every assignment moves through a fixed set of states. A grade above 50 passes. A final reminder cuts work short and forces an immediate submission.

Design

ClassResponsibility
ObserverFormats and prints one message per status change
AssignmentName, status and a private #grade field
StudentOwns assignments, runs work and grading timers, averages grades
ClassListManages students, releases work in parallel, sends reminders
ConceptWhere it appears
Observer patternStudents notify an observer instead of printing, keeping output separate from state
PromisesstartWorking() returns a Promise; releaseAssignmentsParallel() uses Promise.all
Timers500 ms to finish work, 500 ms to grade, 0 ms when a reminder forces submission
EncapsulationThe grade lives in a private class field, reachable only through its methods

A sample run

The demo releases two assignments to two students, starts their work, then sends a final reminder for A1 at 200 ms.

TimeEvent
0 msA1 and A2 released to Alice and Bob in parallel; Alice starts A1, Bob starts A2

≈200 msForced A1 submissions are graded immediately
500 msBob's A2 work timer ends and he submits
