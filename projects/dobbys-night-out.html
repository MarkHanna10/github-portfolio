Game systems

SystemHow it works
NoiseBumping into obstacles fills a noise meter. A full meter wakes the baby and restarts the level.
Currency and storeDobby collects spiders and spends them on powers such as Cat Smack and Muscle Up.
InventoryItems are ScriptableObjects, collected from chests, doors and pickups.
NPCsDialogue characters, and enemies that follow the player.
Match-3 puzzleSwap tiles, clear matches, collapse and refill the board; each match moves the boat build forward.
PresentationTimeline cutscenes, hats Dobby can switch between, menus, music and sound effects.

My part: the Cat Smack ability

I built the first combat ability in the game. Cat Smack is a short-range melee attack: press C, and every enemy inside a box in front of Dobby takes damage. I designed it around a shared IDamageable interface, so any object can take a hit without the attack knowing what it is.

Timing

The hit check

Collider2D[] hitEnemies = Physics2D.OverlapBoxAll(
    attackPoint.position, hitboxSize, 0f, enemyLayers);

foreach (Collider2D enemy in hitEnemies)
{
    IDamageable damageable = enemy.GetComponent<IDamageable>();
    if (damageable != null)
    {
        damageable.TakeDamage(damage);
    }
}

The team later folded the ability into a store system, where Dobby buys Cat Smack with spiders. It ships in the final game on the same C key.
