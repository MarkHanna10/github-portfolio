4-bit ALU on FPGA

A 4-bit arithmetic logic unit written in VHDL, simulated for timing, then run on an Intel MAX10 FPGA with results shown on LEDs and a 7-segment display.

Design

Two 4-bit inputs and an operation select go into the ALU. Arithmetic runs through a 4-bit ripple-carry adder, and the result drives the board's LEDs and 7-segment display.

The ripple-carry adder

Four full adders sit in a chain. Each one adds a pair of bits plus the carry from the stage before, so the carry "ripples" from bit 0 to bit 3. That chain is the critical path.

Full adder outputBoolean expression
SumS = A ⊕ B ⊕ Cin
Carry outCout = A·B + Cin·(A ⊕ B)

Timing and resources

Simulation predicted the worst-case propagation delay, and testing on the FPGA matched it within 5%. At 50 MHz each clock cycle lasts 20 ns, so the 18 ns path finishes with 2 ns to spare.
