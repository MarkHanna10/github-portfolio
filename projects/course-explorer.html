Course Explorer

A browser app for exploring a course catalog. Load a JSON file, then filter, sort and open any course, with no framework and no server.

How data moves through the app

Everything happens in the browser. The File API reads the upload, the app checks it, and only valid data reaches the screen.

  1. Read fileFile API, .json only
  3. ValidateParse and check shape
  5. Build objectsOne Course per entry
  7. Filter, then sortFour filters, six sort orders
  9. RenderEscaped before display

Filter menus fill themselves from the loaded data, so any catalog works without code changes.

Validation

Each check stops the load with a specific message, so the user knows what to fix.

CheckMessage shown
No file chosenNo file selected.
Extension isn't .jsonInvalid file type. Select a JSON file.
Text isn't valid JSONInvalid JSON file format.
Top level isn't an arrayJSON must contain an array of course objects.
Array is emptyJSON contains no courses.
An entry lacks a string idJSON contains incomplete course entries.

Values from the file are escaped before they go into the page, so a course description can't inject HTML or scripts.

Filtering and sorting

ControlOptions
FiltersDepartment, level, credits, instructor. All four combine.
SortID A to Z or Z to A, title A to Z or Z to A, semester earliest or latest first

Sorting semesters correctly

Sorting "Fall 2025" and "Winter 2026" as text puts them in the wrong order. Each semester becomes a number instead: the year times 10, plus the season's place in the year.

SemesterCalculationSort key
Fall 20242024 × 10 + 420,244
Winter 20252025 × 10 + 120,251
Spring 20252025 × 10 + 220,252
Fall 20252025 × 10 + 420,254
Winter 20262026 × 10 + 120,261
 Season order: Winter 1, Spring 2, Summer 3, Fall 4.
